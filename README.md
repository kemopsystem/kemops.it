# KemOps website

Sito statico ufficiale di [kemops.it](https://kemops.it), realizzato in HTML, CSS e JavaScript e pubblicato tramite GitHub Pages.

## Anteprima locale

Apri `index.html` direttamente nel browser oppure avvia un server statico dalla root del progetto.

## Pubblicazione

Ogni push sul branch `main` avvia il workflow GitHub Pages. Il file `CNAME` configura il dominio personalizzato `kemops.it`.

Prima della pubblicazione commerciale, completare i dati societari nell'informativa privacy e verificare l'indirizzo `info@kemops.it`.
